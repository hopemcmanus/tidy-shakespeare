About This Glossary

This glossary has a list of terms used in the Tidy Shakespeare project. Each term has a definition, a category and a reference, primarily Text Mining with R by Julia Silge and David Robinson.

Term Definition Category Reference
Document-Term Matrix A matrix where rows represent documents (plays), columns represent terms (words), and values represent frequency or TF-IDF scores. Data Structures Document-Term Matrices
Inverse Document Frequency (IDF) Decreases the weight for commonly used words and increases the weight for words that are not used very much. Calculated as log(total documents / documents containing term). Frequency Analysis Zipf's Law
TF-IDF Term Frequency-Inverse Document Frequency. A numerical statistic that reflects how important a word is to a document in a collection. High TF-IDF means the word is frequent in this document but rare in others, making it distinctive. Frequency Analysis TF-IDF
Term Frequency (TF) How frequently a word appears in a document. Calculated as the number of times a term appears divided by total terms in the document. Frequency Analysis Term Frequency
Zipf's Law The observation that word frequency is inversely proportional to its rank. The most frequent word appears approximately twice as often as the second most frequent word, three times as often as the third, etc. Frequency Analysis Zipf's Law Explained
Bigram A sequence of two adjacent words. Used to examine word pairs and common phrases (e.g., 'good night', 'fair lady'). N-grams and Relationships N-gram Tokenisation
Correlation A measure of how often words appear together relative to how often they appear separately. Used to find word pairs that commonly co-occur. N-grams and Relationships Pairwise Correlation
N-gram A contiguous sequence of n items (words) from text. Bigrams are 2-grams, trigrams are 3-grams, etc. N-grams and Relationships N-grams & Word Combinations
Pairwise Correlation Examining relationships between pairs of words to find which words tend to appear together in the same section or scene. N-grams and Relationships Correlation Analysis
Betweenness Centrality Measures how often a node lies on the shortest path between other nodes. High betweenness indicates importance in connecting different parts of the network. Network Analysis Network Centrality
Degree Centrality The number of direct connections a node has. High degree indicates a character/word that connects to many others. Network Analysis Centrality Measures
Edge A connection between two nodes in a network graph, representing a relationship (e.g., characters appearing together or word co-occurrence). Network Analysis Network Edges
Network Graph A visualisation showing relationships between entities (characters or words) as nodes connected by edges. Network Analysis Network Visualisation
Node A point in a network graph representing an entity (e.g., a character or word). Network Analysis Bigram Networks
Act-Scene Structure Shakespeare's organisational system dividing plays into major sections (Acts) and smaller segments (Scenes). Used as document boundaries for some analyses. Project-Specific Text Mining with R
Character Network A network where nodes represent characters and edges represent co-occurrence (appearing in the same scene). Edge weight indicates how many scenes they share. Project-Specific Character Networks
Dialogue vs Directions Two main text classes in plays: dialogue (spoken by characters) and stage directions (describing action). Analysed separately or together depending on research question. Project-Specific Tidy Text Mining
Word Correlation Network A network showing which words tend to appear together in sections of text, with correlation strength determining edge weight. Project-Specific Word Correlations
AFINN Lexicon A sentiment lexicon that assigns words a score from -5 (most negative) to +5 (most positive). Created by Finn Årup Nielsen. Sentiment Analysis AFINN Sentiment Lexicon
Bing Lexicon A sentiment lexicon that categorises words into binary positive/negative sentiment. Created by Bing Liu and collaborators. Sentiment Analysis Bing Sentiment Lexicon
NRC Lexicon National Research Council Canada lexicon that categorises words into emotions (joy, fear, anger, etc.) and positive/negative sentiment. Sentiment Analysis NRC Emotion Lexicon
Sentiment Analysis Computational identification and categorisation of opinions in text to determine emotional tone (positive, negative, neutral). Sentiment Analysis Sentiment Analysis
Sentiment Lexicon A dictionary of words labelled with sentiment scores or categories. This project uses three: Bing (positive/negative), AFINN (numeric scores), and NRC (emotions). Sentiment Analysis Sentiment Lexicons
Stop Words Common words (e.g., 'the', 'a', 'and') that are often removed from analysis. This project uses extended stop words including Shakespearean terms like 'thou', 'thee', 'thy'. Tidy Principles Word Frequencies
Tidy Data Each variable forms a column, each observation forms a row, each type of observational unit forms a table. Applied to text: one-token-per-row format. Tidy Principles Tidy vs Non-Tidy Text
Tidy Text A table with one-token-per-row, where each row represents a single word along with its metadata (play, act, scene, character). Follows tidy data principles. Tidy Principles Tidy Text Format
Token A meaningful unit of text (typically a word) extracted during tokenisation. In this project, tokens include individual words from Shakespeare's dialogue, stage directions, and references. Tidy Principles Tokenisation
Tokenisation The process of breaking text into individual words or meaningful units. Uses unnest_tokens() to convert text data into one-token-per-row format. Tidy Principles Unnest Tokens Function
